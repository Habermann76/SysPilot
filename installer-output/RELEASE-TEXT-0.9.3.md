# SysPilot 0.9.3.1 beta

## Was ist neu?

- **Updates**: Neuer Button „Updates" im SysPilot-Fenster zeigt die installierte Version und sucht beim Start im Hintergrund auf GitHub nach einer neueren Version. Ein Klick lädt den Installer und aktualisiert; eigene Einstellungen bleiben erhalten. Abschaltbar über das Tray-Menü.
- **Guardian**: SysPilot startet mit Windows unsichtbar im Infobereich und wird regelmäßig geprüft. Falls es nicht läuft, startet der Guardian es neu. Ein bewusstes „Beenden" im Tray-Menü wird bis zur nächsten Anmeldung respektiert.
- **Automatischer Start**: Nach der Installation oder einem Update startet SysPilot automatisch — auf Wunsch unsichtbar im Tray.
- **Einstellungen bleiben erhalten**: Startverhalten, Guardian, Autopilot, Sprache/Einheit und Update-Suche werden beim Update übernommen.
- **Bewusst schlank**: SysPilot bleibt eine native PowerShell-/WPF-Anwendung und keine Electron-App. Dadurch wird unnötiger RAM-Verbrauch vermieden; das Ziel sind viele clevere Funktionen in einem kleinen Tool.
