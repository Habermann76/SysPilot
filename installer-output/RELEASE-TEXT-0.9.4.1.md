# SysPilot 0.9.4.1 beta

## Änderungen

- Verbindliche KI-Projektregeln in `AGENTS.md`: erst testen, dann Versionsnummer/Release anbieten.
- Toolbox startet Werkzeuge zentral, mit sauberem Arbeitsordner, Admin-Erhöhung und Fehlermeldung.
- Toolbox-Tooltips enthalten Erklärungen; Rechtsklick bietet eine KI-/Web-Suche zum Werkzeugthema.
- Tray-Tooltip wird sicher auf die Windows-Grenze gekürzt und bei Aktualisierung zuverlässig erneuert.
- GitHub-Fallback über `scripts/github-fallback.ps1`, falls GitHub MCP nicht verfügbar ist.
- Installierte Einstellungen und bestehende Projektstruktur bleiben bei Updates erhalten.

Ein GitHub-Release wird erst nach ausdrücklicher Bestätigung erstellt.
